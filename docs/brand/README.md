# Screenkeeper's pictures

Drawn from the app's own launcher icon (`app/src/main/res/drawable/ic_fg.xml` on `#13343A`), so they match it.

| File | Where it's used |
|---|---|
| `screenkeeper-icon.png` (256 px, rounded) and `.svg` | Top right of the README |
| `screenkeeper-avatar.png` (512 px, square) | The avatar of an account or organization that holds this repository: GitHub shows the owner's avatar beside the repository's name, so a repository can't have one of its own |
| `screenkeeper-social.png` (1280 × 640) | Settings › General › Social preview: the picture shown when a link to the repository is shared |

The F-Droid listing on siansa.app has its own copy of the icon in the server kit (siansa-dev, `deploy/fdroid/icons/app.screenkeeper.png`).
